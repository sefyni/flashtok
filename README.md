# FlashTok

Mes flashcards de révision à scroller façon TikTok. Marche hors ligne et s'installe sur l'écran d'accueil.

- Matières, cartes, démos, trous, vrai/faux, points clés, astuces : `cards.js`
- Tap = retourner · note au dos (Raté / Hésité / Facile) · double tap = favori
- Glisser à gauche = compte de la matière (grille, fiches de chapitre) · glisser à droite = feed précédent
- Pour toi (répétition espacée), CC avec compte à rebours, mode contrôle /20 avec questions de cours
- Série + gels (gagnés avec les défis du jour), thèmes et ambiances
- Bouton Réviser : session guidée (nombre de cartes au choix), plan de colle jour par jour, QCM concours A–E (barème LAS), schémas à compléter, mes erreurs, mode écoute
- Sauvegarde de la progression par code · sons et musique générés en direct (`audio.js`)

## Installer sur l'iPhone

Ouvrir https://sefyni.github.io/flashtok/ dans Safari, puis Partager → « Sur l'écran d'accueil ».
